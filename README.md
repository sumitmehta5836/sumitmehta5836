Sahayak Setu - Find, book and track verified local workers, while giving them fair pay, transparent pricing and real safety protection.

**✨ Highlights**
- 🤖 **Gemini-powered AI assistant** that answers in English, Hindi and Hinglish, and only calls allowlisted backend functions, so it never runs raw SQL or invents workers
- 📍 **Live worker tracking** on a map with route and ETA, visible only to the worker, an admin, or a customer with an active booking
- 🔥 **Complaint and demand heatmap** filtered by trade
- 🛡️ **Worker Suraksha**, a micro-insurance prototype for gig workers
- 🚨 **Emergency SOS** that captures GPS location and logs an incident
- 😮‍💨 **Fatigue score and break controls** to protect workers from burnout
